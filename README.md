# AutomateIQ Blog

SEO blog for the **OMEGA studio** — practical automation guides for agencies and small businesses: n8n workflows, AI lead follow-up, lead scoring, CRM hygiene, and productized services.

## Structure

- `content/` — 10 long-form articles (Markdown)
- `build.py` — static site generator (Markdown → HTML in `dist/`)
- `assets/` — images and static files

## Build

```bash
python3 build.py
```

Output goes to `dist/`, ready to deploy on any static host (Vercel, Netlify, GitHub Pages).
